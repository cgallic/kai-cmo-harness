# Public Skill Manifest Example Artifacts

Use this inventory when adding example links to public `kai-*` skill manifest pages.

## Linking Rule

Public manifest pages must link only to real files that exist in this repository. If a skill does not have a committed/local example artifact in `workspace/`, `examples/`, `docs/`, or an obvious sample-output folder, write `No committed example artifact found` instead of inventing a sample.

## Search Boundary

This inventory is limited to repo-owned artifact areas: `workspace/`, `examples/`, `docs/`, and obvious sample-output folders under those paths. It intentionally ignores app/cloud skill caches, dependency folders, and worktree/cache directories.
