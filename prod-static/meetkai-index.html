FAQ

What you need to know before installing Kai.

Kai runs locally through Claude Code. The dashboard and connected tools are optional layers.

What is Kai?

Kai is an open-source marketing system for Claude Code. It uses your repo context to plan, create, audit, and check marketing work.

Is Kai only a chat box?

No. Kai installs task-specific marketing skills in Claude Code. Each skill loads the right brief, framework, checklist, and quality gate.

What can Kai create?

Kai can draft landing pages, emails, ads, SEO briefs, social posts, newsletters, competitor notes, case studies, launch plans, and campaign plans.

What does Kai check?

Kai checks usefulness, specificity, claims, banned words, search structure, ad policy, approval status, analytics gaps, and phone lead capture.

What tools can Kai connect?

Kai supports analytics, CRM, ads, email, website, calendar, phone, and publishing integrations. Execution requires your credentials and approval. Some live feeds are still being connected.

Where does KaiCalls fit?

KaiCalls is a Kai-owned phone lead option. Consider it when missed calls, after-hours answering, qualification, or routing is a documented problem.

Can agents sign up for KaiCalls?

Yes. Agents can use the KaiCalls signup docs or download the KaiCalls agent skill when a workflow needs phone, SMS, and lead capture.
