## Design Notes (for implementation)

- **Color palette:** Dark background (terminal aesthetic), green/cyan accents (code vibes), clean white text
- **Typography:** Monospace for code blocks and the install command. Clean sans-serif (Inter or similar) for body copy
- **Layout:** Full-width sections, generous whitespace. Mobile-first.
- **Hero:** Large text, no background image. Let the words work.
- **Install block:** Should feel like a terminal — dark card with monospace text and a copy button
- **Demo GIF:** Actual terminal showing Kai in action. No mockups. Real output.
- **KaiCalls section:** Warmer tone shift — this is about people, not code. Consider a subtle color shift (warm accent vs cool accent for Kai CMO)
- **Social proof:** Simple logo row, not a complex carousel
- **Services CTA:** Intentionally understated. One line of text and a button. Not a sales pitch.
