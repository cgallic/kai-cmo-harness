# Access checklist

**Trigger:** `client.signed` (Loops event)
**Segment:** New client
**Stage:** Onboarding
**Send timing:** Immediate after contract signature

## Subject Line
Primary: First, send these 5 items
Variant A: Your launch checklist
Variant B: What we need before kickoff

## Preview Text
Send these five items so we can build the first ad test correctly.

## Body
Welcome aboard.

Before kickoff, we need five items so the first test is built on real business context instead of guesses.

1. Meta Business Manager access.
2. Ad account access.
3. Pixel or Conversions API status.
4. CRM or call tracking access.
5. The service line and ZIP cluster we agreed to test first.

The CRM or call tracking step matters most. If we cannot see what happens after the lead form, the report will over-credit cheap names and under-credit serious conversations.

We will check access within one business day. If anything is missing, you will get a short list of fixes before kickoff.

Your first creative test will not go live until tracking, service area, offer, and lead handling are all confirmed. That is slower than pushing random ads live today. It is faster than spending a month on numbers nobody trusts.

If one item is hard to find, send what you have and tell us who owns the rest. We can help identify the missing access, but we need a named owner so the launch does not stall in a shared inbox.

Once access is confirmed, we will send a short readiness note. That note will say what is approved, what is missing, and whether the kickoff can stay on schedule.

## CTA
Send the five launch items.
