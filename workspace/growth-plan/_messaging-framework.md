# Kai Marketing OS Messaging Framework

## Positioning Statement

For founder-operators, agencies, and developer-led growth teams who need marketing work tied to the product source of truth, **Kai Marketing OS is a repo-native marketing runtime** that helps agents plan, write, gate, and log campaigns from inside the workspace. Unlike blank chat tools or prompt packs, Kai ships with skill contracts, policy references, playbooks, quality gates, and reusable product memory.

## 10-Second Pitch

Kai turns your repo into a marketing workspace for Claude Code.

## 30-Second Pitch

Kai Marketing OS gives Claude Code a marketing operating system: product context, channel playbooks, platform policy, content quality gates, and 33 public `/kai` workflows for planning, writing, launch, SEO, ads, email, CRO, and AI-search work. It is built for operators who want marketing output that starts from the repo and leaves a reusable record behind.

## Message Pillars

| Pillar | Headline | Proof To Show |
|---|---|---|
| Repo-native context | Marketing starts where the product lives | `MARKETING.md`, README parsing, workspace outputs |
| Governed execution | Drafts are checked before they ship | Four U's, banned words, SEO lint, ad policy references |
| Full-funnel workflows | One router covers planning, production, audit, and research | 33 public `/kai` commands and skill contracts |
| Reusable memory | Every run leaves context for the next run | publish logs, 30-day checks, workspace artifacts |
