# Kai Marketing OS Metrics Dashboard

## Activation Metrics

| Metric | Target | Why It Matters |
|---|---:|---|
| README visitor to install click | Baseline first, then improve | Measures repo conversion |
| Install to first `/kai` run | 30%+ of installers | Shows setup clarity |
| First run to generated `MARKETING.md` | 70%+ of first runs | Shows onboarding reliability |
| First run to useful output | 50%+ of first runs | Shows product value |
| Time to first useful output | Under 10 minutes | Core promise is fast repo-native marketing work |

## Demand Metrics

| Metric | Target | Why It Matters |
|---|---:|---|
| GitHub stars from relevant audiences | Track source | Directional awareness signal |
| Teardown requests | 5-10 per month early | Strong hand-raiser signal |
| Newsletter or waitlist signups | Baseline first | Captures future demand |
| Community replies with repo links | Rising weekly | Shows the teardown offer is working |
| Demo completion rate | 40%+ | Shows the story is legible |

## Quality Metrics

| Metric | Target | Why It Matters |
|---|---:|---|
| Generated assets passing gates | 80%+ after one revision | Proves governance story |
| Banned-word failures in public copy | 0 Tier 1 | Product must follow its own rules |
| Count consistency across docs | 100% | Prevents trust leaks |
| Case studies with real evidence | 3 by day 90 | Shifts proof from inventory to outcomes |
